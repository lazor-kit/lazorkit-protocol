# moves a binary turns that check red until this file (and the tables in
# docs/mainnet-deploy-checklist.md) record the new hashes. A red check stops a
# merge only where the repository makes release-hashes a required check. A
# mismatch with no program change means the build is not reproducible on that
# machine: stop and find out why before deploying.
